Hyundai Automotive Supply Chain, Manufacturing & Export Intelligence

Project Overview

This project focuses on Hyundai's automotive supply chain, manufacturing, inventory, logistics, imports, and exports.
The goal is to understand business operations using data and create useful insights through SQL and Power BI.

Project Objectives

Analyze manufacturing and quality performance.
Understand inventory and logistics operations.
Analyze vehicle exports and international markets.
Study import and customs-related operations.
Support business decisions through data analysis.

Tools Used

PostgreSQL,SQL,Power BI,GitHub

Power BI Dashboards

Manufacturing & Quality:
Analyzes manufacturing operations and quality performance.

Inventory & Logistics:
Provides insights into inventory and logistics operations.

Export & Customs:
Focuses on vehicle exports and customs-related activities.

Import:
Provides insights into import-related operations.

Data Sources:

Company information and relevant automotive data are collected from available sources. Official reports are used wherever applicable.

Key Learning Outcomes:

SQL queries and database management
Data analysis and business reporting
Interactive Power BI dashboards
Automotive supply chain understanding
